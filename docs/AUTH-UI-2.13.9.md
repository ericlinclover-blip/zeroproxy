## 页面与交互

- 沿用连接场域已有的米白、深绿、荧光绿令牌与系统字体，不引入外部图片、字体或构建依赖。
- 桌面采用分栏：登录页展示设备—节点—网络路径，初始化页展示填写配置、自动部署、进入面板三个阶段；手机采用单列。保留内容自然滚动，不用固定高度裁切长表单或部署结果。
- 两个页面均使用原生表单、关联标签、密码管理器自动填充、密码显隐、回车提交与必填校验；无 JavaScript 时表单也不会把密码写入 GET 查询串。
- 登录等待时防止重复请求；错误使用 alert 并获得焦点，保留账号供重试；成功后清空密码并恢复隐藏。
- 初始化部署期间锁定配置、显示不定进度与真实等待说明；失败后恢复填写和重试。保留引导令牌保护、部署结果、正式域名交接与留在本页的原有流程。
- 修正“管理员密码同时作为代理口令”的过时文案，实际节点凭据独立生成。入口页隐藏主机、账号、运行时间等仪表盘页脚详情。
- 跳转链接随当前视图指向表单或工作区，支持键盘焦点和系统减少动态效果设置。
