# v2.13.3 / 路由器 v1.4.53：LuCI 宿主适配

## 修正原因

v1.4.52 把独立管理页直接放入固定 `78vh` 的 iframe。独立页的主题、宽边距和大标题与 LuCI/Argon 外壳叠加，造成嵌套面板、尺寸不协调与两层滚动。独立页截图无法覆盖这个场景。

## 变化

- LuCI 承载页读取同源宿主的内容背景、正文颜色、字体和强调色，映射到内部界面的语义变量。不修改 OpenWrt 的全局主题设置。
- 监听宿主根节点、内容祖先、主题样式与系统明暗变化。没有可读取的强调色时采用中性蓝色；文字与表面不匹配时使用可读的明暗文字。
- LuCI 内部使用紧凑标题、导航、卡片间距和连接视图；移除独立主题开关，避免一页内两套明暗偏好。独立管理地址仍保留原有主题和用户偏好。
- iframe 根据内容高度自动增高和缩回，交给外层页面滚动，不再以固定视口高度裁切。卸载承载页时清理观察器与事件监听。
- 节点接口读取失败或没有可用代理组时，清除静态的“自动选择 / 就绪”，展示未知或未提供，并禁用不适用的全部测速。
- 安装包内置的 LuCI 承载页同步更新；升级时原子刷新离线修复缓存，写入失败保留原文件。不会在离线修复时还原旧的固定高度承载页。

## 升级顺序

1. 服务器面板升级到 v2.13.3，提供新版安装脚本和界面文件。
2. 路由器“维护 → 更新客户端”，或在 SSH 中执行 `zeroproxy update`，升级到 v1.4.53。
3. 完成后强制刷新**整个 LuCI 页面**，不是仅点击内部刷新。Mac 可用 `⌘⇧R`，Windows/Linux 可用 `Ctrl+Shift+R`。LuCI 外层已加载的旧承载脚本也需要重新读取。

本轮没有改 Go 核心、透明代理配置或 LuCI 登录与授权规则。

## 验证范围

浏览器使用仓库中的真实 `status.js` 创建 iframe，嵌入本机模拟的 LuCI 外壳；不是只测试独立页面。覆盖蓝白、深色、自定义强调色、宿主内容表面单独换色、文字对比度、五工作区和六种宽度，并验证长页面切换到短页面后承载高度会缩回。

运行脚本测试在临时目录中实际执行缓存刷新，覆盖正常替换与 `mv` 失败保留旧文件。详细结果见 [VALIDATION.md](VALIDATION.md)。截图是模拟 LuCI 外壳下的实际浏览器渲染，尚未在用户真实 Argon 固件上部署验证。
