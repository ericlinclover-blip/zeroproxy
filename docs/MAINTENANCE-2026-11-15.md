# 第一轮修复记录

基于 v2.12.35（7756a30），本轮版本为面板 **2.12.36**、路由器客户端 **1.4.51**。修复代码完成本地验证后提交推送，未部署。CI 工作流因仓库写入凭据缺少 `workflow` 权限而保留本地，尚未推送。

## 修复内容

### 状态一致性与失败恢复

- WireGuard 使用可重入的非阻塞事务锁与 flock，覆盖 API 修改、恢复、配置应用和到期回收。事务锁覆盖读改写到同步完成，全局状态锁仍保持短持有。
- 并发事务返回明确的 409，调用方稍后重试；旧回执不再覆盖最新 WireGuard 配置。
- 同步失败恢复期望状态并尝试补偿运行配置，分别记录状态回滚与运行配置恢复结果，不把补偿失败写成成功。
- 新增设备同步失败时，不返回未提交的密钥配置。
- 到期回收在全局锁外执行耗时同步；失败后下一轮重试。
- 后台 Geo 更新的应用阶段与普通应用任务串行，避免竞争生成文件。
- 配置生成/校验失败时恢复先前的 Xray、nginx、Hysteria、WireGuard 配置文件和权限；撤销生成阶段临时补齐的状态字段。
- 证书生成失败阻止继续应用；包含失败步骤的后台任务标记为 failed。前端未取得任务完成结果时不再显示成功。

### 防护与规则

- Xray 的私网隔离与固定广告、追踪、威胁域名防护不再依赖 Geo 数据文件。
- 私网隔离位于域名放行白名单之前，使用按需地址解析，覆盖域名解析到私网的情况。
- 无 Geo 数据时修改基础防护也触发服务端配置应用。
- dae 正确区分域名、IPv4、IPv6 和 CIDR，冲突优先级与 Clash 一致，且在降级模式保留国内域名直连。
- Clash、sing-box 的裸 IP 规则补齐 /32 或 /128；IPv6 管理面地址生成 IP-CIDR6 规则。
- sing-box 全局模板补齐 AI/流媒体/落地策略；自定义规则优先于普通私网直连。
- Clash 配置和规则预估共用有序规则。移除域名子串、“.cn 就属于中国”等未经数据库验证的判断，明确标注 Geo/DNS 未验证与客户端选组的影响。
- 域名/IP/CIDR 输入执行严格校验；非法配置字符、错误地址和白名单中的网段明确拒绝，不悄悄吞掉。
- dae 仍使用统一代理组；这一限制已显示在配置注释和路由器界面，没有宣称其独立选组与 mihomo 等价。

### AWG 协议与配置

- 客户端导出协议必须匹配服务端；混淆开启时拒绝导出不匹配的标准 WireGuard 配置，以及启用标准兼容设备。
- 检查 H1~H4 互异及参数范围，保留 Jc/Jmin/Jmax/S1/S2 的合法零值。
- 探测 AWG 自己的内核接口类型、工具及 amneziawg-go/TUN；不把标准 WireGuard 的可用性当作 AWG 可用。
- 启动与同步脚本缺 AWG 工具时明确失败，不将混淆配置交给标准工具尝试。
- WG/AWG 协议切换重建接口；普通 peer 修改继续增量同步。切换协议会短暂断开连接。
- WireGuard 生成文件复用公共原子写盘函数，临时文件从创建时即受限权限保护。

兼容依据与安装资料见 [验证说明](VALIDATION.md) 中的官方资料链接。本轮维护现有基础 AWG 参数子集，没有扩展到上游全部新协议特性。
