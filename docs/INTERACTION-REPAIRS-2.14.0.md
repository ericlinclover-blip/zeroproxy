## 运行可靠性补强

- 新增显式节点 `enabled` 接口，相同目标重复提交不反转；旧 `/toggle` 保留兼容。节点与设置可检查 `expected_revision`，旧页面提交冲突时返回 409。
- 公共请求有 AbortController 时限，任务轮询按实际时间计算截止期限；长耗时证书、WG 和修复使用独立预算。请求超时不会自动重放变更。
- 后台任务使用随机 ID，摘要落盘，保存会话所有者的哈希而非原始 cookie；查询仍检查当前会话有效性。刷新后可继续查询，进程重启遗留任务标为 interrupted，不自动执行第二次。
- 记录期望配置版本和已应用版本；初始部署与后续应用都保留最近成功配置。生成校验失败恢复旧文件；服务应用失败尝试恢复旧运行配置并验证，补偿失败单独显示。
- 保留失败期望配置供修改重试。确认旧运行配置保留/恢复后，主订阅使用最近成功配置，避免把失败候选作为可用配置发布。
- 诊断页可显式恢复最近成功配置。账号、会话和当前设备登记保留；恢复动作仍需生成、校验并应用。
- 域名切换不再把业务错误当作断线成功；新入口未确认可达时保留当前页面。

新增本地文件均在原数据目录中：`data/apply-jobs.json`、`data/runtime-last-good.json`。后者含运行配置密钥，按 0600 原子写入，不经前端下发完整快照。

## 可选的设备独立凭据

设备页增加“启用独立凭据”。这是显式迁移，不会在升级时擅自迁移现有设备。

- 为设备分配独立 VLESS UUID、Trojan 和 Hysteria 口令；普通 Xray 入站及链式入口支持这些身份，不把设备加入链式落地端的服务间授权。
- 标准模式与 dae 性能模式均使用设备专属身份。应用未确认成功时不下发该设备的新授权；失败后可以重试。
- Hysteria 使用其官方 command authenticator，本机认证程序读取原子写入的 0600 白名单，程序为 0700；无需依赖面板 HTTP 服务，因此面板临时离线仍能完成本机认证。它会在新握手时启动认证程序，高并发新建连接的成本尚未做真机基准。
- 移除独立身份会更新运行配置与认证白名单。新连接授权可以单独撤销；已有会话是否中断取决于内核重载和会话生命周期，不能承诺所有既有连接瞬间消失。
- **曾拿到过共享节点凭据的设备仍可能用旧共享配置连接。** 迁移独立身份不等于抹掉它曾获得的凭据，需要另行轮换共享凭据。界面在迁移、移除时均说明这一点。

依据：[Hysteria 官方认证配置](https://v2.hysteria.network/docs/advanced/Full-Server-Config/)、[官方 command authenticator 实现](https://github.com/apernet/hysteria/blob/master/extras/auth/command.go)。

## 交互流程改进

- 首页增加“路线检查 / 设备状态 / 下一步”摘要，保留现有连接图作为路径检查器；未验证的设备段继续显示未知。
- 设备增加控制权、期望与实际状态、下载/应用版本及回报说明详情。
- 修复额外发现的设备模板问题：单设备模板进入配置版本，优先于安装 URL 残留的 `rules=smart`，标准与性能模式保持一致，心跳返回有效模板。
- 维护区增加配置版本与本会话任务历史，并接入快捷查找。
- 服务器高级修改和一键修复先展示影响计划；分流规则保存先展示作用范围、优先级、数量及相同目标冲突。
- 诊断明确设备/DNS 与服务器检查边界，每个失败给下一步；可导出字段白名单构成的脱敏摘要，不导出原始仪表盘、异常原文、地址、token、私钥、口令或配对码。

规则预览目前识别跨组相同目标，不宣称完整识别所有 CIDR 包含关系。设备实际 DNS、接管和目标出网需要设备端验证；没有把服务器 HTTP 响应包装成设备出网证明。

## 验收记录

最终命令与结果同步记录在 `docs/VALIDATION.md`。新增测试为 `backend/tests/test_interaction_audit.py` 与 `scripts/audit_ui_check.cjs`。
