# v2.13.2 连接图交互改进

连接图从配置展示改为路线检查入口，沿用现有骨白、墨黑、酸柠绿主题。本轮修改与尚未发布的路由器 v1.4.52 配套界面一起保留在 v2.13.2 中。

## 可以直接完成的操作

- 在画布顶部选择节点或落地端；查看本身不会修改分流或默认出口。
- 点击设备、入口、出口三段，查看各段的证据、范围、地址与下一步操作。
- 设备段可进入设备接入工作区；入口段可定位所选节点；出口段可定位落地条目或分流规则。
- 针对当前节点执行独立检查，不再通过隐藏的“全部测速”按钮扫描其它节点。
- 链式连接可检查落地段并显示实测出口 IP。设置默认出口沿用原有确认窗口与配置应用流程。
- 异常或请求失败时提供完整诊断入口。检查期间显示进度并阻止重复提交；切换查看对象不会使异步结果串到其它路线。

## 证据与显示边界

- 单独展示探测耗时、验证层级、结果时效；超过五分钟的结果标为过期。
- TCP/TLS 握手、UDP 监听和真实客户端出网是不同层级。缺少内核或环境不支持时显示未完成，不降级冒充完整成功。
- Hysteria 2 当前没有接入完整客户端探测，按钮明确写作“检查 UDP 监听”。
- 已通过的落地段不能证明链式节点本地入口已通过，亦不能证明设备接入正常。
- 设备到入口始终保留未验证标记；服务器检查成功只高亮后半段。移除没有实际路由含义的装饰性备用路径。
- 单节点 API 只接受已知节点；探测前后核对配置，期间配置变化返回 409 并丢弃结果。缓存区分路线及实际配置，避免同秒修改凭据后复用旧结果。
- 检查请求失败保留上次证据，明确提示未取得新结果，不将 HTTP 错误认作节点故障。不会自动重放配置操作。
- 收紧标题、图形和详情占用，保留键盘焦点；手机端采用可点击的纵向路径。

## 验证方式

使用隔离的本机开发面板、Chromium 和模拟探测响应验证交互；API 测试验证检查范围、鉴权、未知节点、环境缺失、配置并发变更与缓存隔离。具体结果记录在 [VALIDATION.md](VALIDATION.md)。截图来自本机测试环境，不能替代真实服务器和客户端的连接验收。
