# v2.13.0 · 连接场域界面升级

本次将批准的第二版设计落实到真实面板，保留 FastAPI、原生 ES Modules 与现有 API；无新增运行依赖，无配置迁移。路由器客户端版本仍为 v1.4.51。

## 实际变化

- 骨白、墨黑、酸柠绿视觉系统；默认浅色，保留已保存的深浅色偏好。
- 网络、设备、分流、诊断、维护五个工作区。所有表单仍在 DOM 中，切换不丢草稿；后台刷新保留输入与焦点。
- 网络首页以 SVG 连接路径、选中对象检查器与连续参数栏替代传统指标卡片堆叠。长域名、IPv6、系统路径和手机布局允许换行。
- 节点名称与对象选择器可切换预览。查看入口或落地不写配置；节点/链路验证沿用现有 API；设置默认出口复用原有影响确认与应用任务。
- 五分钟以上的探测成功结果退回“上次探测已通过”，不继续亮成当前验证状态；停用、失败、指纹待修复与 QUIC 内层未就绪分别处理。
- 指标区明确为“启用节点”“参考出口 IP”“服务器探测耗时”。路径为配置预览，不代表设备实时流向，不声称所有客户端经过同一出口。
- ⌘K / Ctrl+K 或“查找”打开原生搜索弹窗，可定位节点列表、设备、分流、备份和更新；Esc 关闭，导航保留焦点指示和当前页语义。
- 修复原生 dialog 关闭事件排队后误隐藏重新打开弹窗的问题；解锁检测布局迁移到外部 CSS，避免 CSP 阻止内联样式。
- 小屏连接路径纵向重排；检查器排在路径之后，按钮和完整管理功能均可访问。

## 文件与结构

- `backend/static/app/style/field.css`：主题与工作区布局，覆盖保留的既有组件。
- `backend/static/app/views/workspace.js`：工作区导航、锚点定位和快捷查找。
- `backend/static/app/views/field.js`：真实数据到预览状态的模型与检查器。
- 既有节点、二维码、分流、设备、WireGuard、备份、升级与操作记录逻辑继续复用。
