# v2.15.3：路线检测图圆心定位修复

日期：2026-11-16。面板 v2.15.3；路由器客户端保持 v1.4.59，本轮升级面板即可。

## 原因与修复

桌面曲线使用 SVG `viewBox="0 0 800 230"`，三个连接点为 `(65,150)`、`(320,70)`、`(570,130)`。HTML 圆圈以前按左上角定位，圆心因此额外偏移半个直径；出口 CSS 的 `left:72%` 还与 SVG 终点的 `570/800=71.25%` 不一致。

修复将节点位置写成按 SVG 坐标换算的精确比例，圆圈自身以 `translate(-50%,-50%)` 把圆心落在锚点上。曲线和文字的布局方式沿用现有实现。

移动端使用竖线：背景线和入口至出口状态线统一落在 13px 圆圈的中心轴上，用自身半个线宽居中，避免 1px/2px 线宽切换时横移；起止位置与对应圆心一致。清除了覆盖背景线端点的旧 `bottom:42px` 规则。
