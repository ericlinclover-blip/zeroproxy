链式代理

两台机器接成一条链: 近的做入口加速, 远的做落地出口 客户端只连本机, 出口 IP 是落地服务器
典型用法: 香港机器离你近 (延迟低) 做 入口, 美国机器做 落地 (出口 IP 显示为美国)。 两台都装本程序 → 落地端点「生成配对码」→ 入口端粘贴那行码点「连接并测试」即可。 链式节点对你手机 / 电脑上的客户端就是一个普通节点 (订阅里多一条), 不用手写 Clash relay / sing-box detour 配置; 也不需要在客户端装任何东西。
